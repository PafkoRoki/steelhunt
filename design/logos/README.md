# Logo sources (not served)

Original files supplied by the site owner (EPS, AI, CDR). Converted to `public/logos/*.svg` with
Ghostscript 10.08 (EPS → PDF, `-dEPSCrop`) and Inkscape (PDF/AI/CDR → plain SVG); empty margins trimmed
by adjusting the SVG viewBox. `ritchey.svg` is cropped to the primary logo of the logo sheet.
`diamondback.ai` (old PostScript-based Illustrator format) could not be converted.
